# Sistema de Chamados

Aplicação web para gerenciamento de chamados, desenvolvida em **Python** com **Streamlit** e **SQLite**.

## 🚀 Funcionalidades
- Cadastro e login de usuários
- Abertura e acompanhamento de chamados
- Interface amigável via Streamlit

## 🛠️ Tecnologias
- Python 3.x
- Streamlit
- SQLite
- Pandas
